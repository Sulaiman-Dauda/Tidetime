## Documentation style

The guides in this folder are split by audience on purpose:

- **user guides** avoid technical language as much as possible
- **admin guides** explain product setup in plain English
- **technical guides** stay precise for developers and self-hosters

If you are not sure where to begin, start with [Getting Started](./GETTING_STARTED.md).
