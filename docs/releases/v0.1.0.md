# Tidetime v0.1.0

**Initial public open-source release**

Tidetime `v0.1.0` is the first polished public release of the project: a fast, self-hostable scheduling platform built with Next.js, TypeScript, and PostgreSQL.

This release focuses on shipping a strong core product rather than a bloated feature matrix. The result is a clean, production-oriented base for individuals, teams, and open-source contributors.

## Highlights

### Scheduling core

- personal and team event types
- public booking pages
- round-robin and collective scheduling
- custom booking fields
- booking links and rescheduling/cancellation flows
- timezone-aware slot generation

### Platform features

- REST API with API keys
- HMAC-signed outgoing webhooks
- Stripe-backed paid bookings
- reminder worker and transactional email support
- embeddable booking widget
- analytics, settings, teams, and links dashboard areas

### Production readiness work included in this release

- stricter environment validation for production startup
- improved HTTP security headers
- health endpoint for probes and uptime checks
- ESLint CLI migration and stable type generation workflow
- Dockerfile and production compose stack
- CI workflow, community files, and open-source templates
- architecture, deployment, API, contribution, security, and release documentation

## Notable implementation details

Tidetime is intentionally lean:

- business logic is kept in testable modules under `src/lib`
- server orchestration lives in `src/server`
- PostgreSQL is the single required data service
- sessions, API keys, and encrypted credentials are handled with security-first defaults

## Known scope boundaries

This release is honest about what is and is not fully shipped in the repository.

Production-ready now:

- booking flows
- team scheduling
- API keys
- webhooks
- Stripe payments
- reminders
- self-hosting

Planned but not yet fully shipped as end-user connection flows:

- Google Calendar OAuth connection flow
- Google Meet provider connection flow
- Zoom provider connection flow

## Upgrade / deployment note

If you are running an older local database and encounter query errors about missing columns, apply the latest migrations:

```bash
npm run db:migrate
```
